# Security

Report vulnerabilities privately using **Report a vulnerability** in the [repository's Security tab](https://github.com/TabanAziz/BetterExplorer/security). Include the BetterExplorer version, Windows build, steps to reproduce, and the potential impact. Use sample paths and files in the report.

The current release is a preview. BetterExplorer uses Windows Shell operations for file transfers and the Recycle Bin. The optional Win+E helper runs for the current Windows user. The public portable package is unsigned and includes a SHA-256 checksum.
